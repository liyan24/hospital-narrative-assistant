# 医院叙事生成助手 — 实际使用接口清单

> **说明**：本文档通过扫描 `pages/`（Streamlit 前端）与 `frontend/src/`（React 前端）源码中的实际 API 调用整理而来，仅包含当前项目中**真正被调用**的接口。  
> 与《数据接口规范文档_交付版_v2.0.md》中的“规划接口”不同，本文档用于明确数据团队当前必须优先对接的接口范围。

---

## 一、总体结论

| 前端类型 | 涉及页面/视图数 | 实际使用接口数（去重后） |
|---|---|---|
| **Streamlit（pages/）** | 18 个 .py 页面 | 约 38 个接口 |
| **React（frontend/src/）** | 14 个视图/组件 | 约 27 个接口 |
| **两边合计（去重）** | - | 约 **50+** 个接口 |

> 注意：Streamlit 与 React 前端是两套独立实现，存在功能重叠但接口路径一致的调用。

## 六、对接优先级建议

### P0：必须优先对接（当前核心功能已调用）

1. **叙事类**：`/api/narrative/patient/storyline/{id}`、`/api/narrative/risk-prediction`、`/api/narrative/department-operation`、`/api/narrative/quality-control`、`/api/narrative/rag/ask`
2. **每日简报**：`/api/daily/briefing`
3. **知识图谱**：`/api/kg/stats`、`/api/kg/subgraph/*`
4. **React 管理后台**：`/api/auth/login`、`/api/admin/*`

### P1：重要但可延后（Streamlit 深度分析模块）

- `/api/narrative/comorbidity/*`、`/api/narrative/drug-pattern/*`、`/api/narrative/pathway/{name}`、`/api/narrative/readmission/*`、`/api/narrative/similar-patients/{id}`、`/api/narrative/tcm/*`
- `/api/weekly/*`、`/api/narrative/report/*`

### P2：规划接口（如按“数据方负责计算”架构改造后需要）

- `/api/v1/stats/*` 聚合接口
- `/api/v1/patients/{id}/summary`、`/api/v1/patients/{id}/timeline`
- `/api/v1/wards/current-inpatients`、`/api/v1/wards/beds`
- `/api/v1/dicts`

## 七、备注

- Streamlit 前端通过 `utils/api_client.py` 直接请求 `http://localhost:{APP_PORT}/api/...`。
- React 前端通过 `frontend/src/api/request.js` 统一封装 axios，baseURL 为 `/api`。
- 部分接口在 `frontend/src/api/index.js` 中已定义但未被视图引用（如 `/kg/visualization`、`/auth/me`），标记为“定义中”。
- 当前系统后端仍大量依赖本地 Excel / Neo4j 进行数据存储与计算，与“数据方负责存储计算”的目标架构存在差距，后续需按《数据接口对接实施说明.md》逐步改造。
