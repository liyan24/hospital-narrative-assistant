# 医院叙事生成助手 — 知识图谱示例集合

> **来源**：从 `data/kg_cleaned/cleaned_data.json` 中随机抽取  
> **用途**：供数据团队理解知识图谱的节点类型、属性结构与关系语义  
> **说明**：节点与关系均来自肿瘤血液科真实脱敏数据

---

## 一、节点示例（5 个）

### 1. Patient（患者）

```json
{
  "label": "Patient",
  "patient_id": "4116-002-000000000000000000000093",
  "medical_record_no": "40594",
  "age": 66,
  "marital_status": "已婚",
  "occupation": "无",
  "allergy_history": "无"
}
```

**说明**：`patient_id` 为患者唯一标识，所有就诊、检查、手术、医嘱均通过该字段关联。

---

### 2. Visit（就诊）

```json
{
  "label": "Visit",
  "visit_id": "33840002",
  "patient_id": "4116-002-000000000000000000000021",
  "admission_date": "2019-07-10",
  "chief_complaint": "发现左肺占位6年余",
  "discharge_date": "2019-07-17",
  "length_of_stay": 8
}
```

**说明**：一次就诊由 `visit_id` 唯一标识，连接患者、入院/出院时间、主诉、住院天数等。

---

### 3. Disease（疾病）

```json
{
  "label": "Disease",
  "name": "左肺恶性肿瘤",
  "type": "western",
  "category": "admission,discharge",
  "frequency": 1971
}
```

**说明**：疾病节点已做归一化处理，`type` 区分 `western`（西医）、`tcm`（中医）、`tcm_syndrome`（证型）。`frequency` 表示该疾病在全部就诊中的出现频次。

---

### 4. Drug（药品）

```json
{
  "label": "Drug",
  "name": "中药熏洗治疗",
  "original_names": ["中药熏洗治疗"],
  "count": 4201
}
```

**说明**：药品名称已清洗去除采购标记、规格后缀等。`count` 表示该药品被使用的总次数。

---

### 5. Surgery（手术）

```json
{
  "label": "Surgery",
  "name": "经腔插管消化道造影术",
  "category": null,
  "level": null,
  "anesthesia_method": null
}
```

**说明**：手术节点保存手术名称、类别、等级、麻醉方式等属性。本示例中部分属性为空，实际数据中非空率取决于源数据质量。

## 二、关系示例（5 个）

### 1. HAS_VISIT（患者 → 就诊）

```json
{
  "type": "HAS_VISIT",
  "from": {
    "label": "Patient",
    "id": "4116-002-000000000000000000000021"
  },
  "to": {
    "label": "Visit",
    "id": "33840002"
  },
  "properties": {}
}
```

**语义**：表示某患者拥有某次就诊记录。

---

### 2. DIAGNOSED_WITH（就诊 → 疾病）

```json
{
  "type": "DIAGNOSED_WITH",
  "from": {
    "label": "Visit",
    "id": "33840002"
  },
  "to": {
    "label": "Disease",
    "id": "左肺恶性肿瘤"
  },
  "properties": {
    "diagnosis_type": "admission",
    "is_main": true,
    "type": "western"
  }
}
```

**语义**：某次就诊被诊断为某种疾病。`diagnosis_type` 区分入院/出院诊断，`is_main` 标记是否主要诊断。

---

### 3. CHIEF_COMPLAINT（就诊 → 主诉）

```json
{
  "type": "CHIEF_COMPLAINT",
  "from": {
    "label": "Visit",
    "id": "33840002"
  },
  "to": {
    "label": "ChiefComplaint",
    "id": "发现左肺占位6年余"
  },
  "properties": {}
}
```

**语义**：某次就诊的主诉内容。主诉文本已做清洗，去除了治疗后缀等无关信息。

---

### 4. PERFORMED_EXAM（就诊 → 检查）

```json
{
  "type": "PERFORMED_EXAM",
  "from": {
    "label": "Visit",
    "id": "48054003"
  },
  "to": {
    "label": "Exam",
    "id": "磁共振平扫"
  },
  "properties": {
    "exam_date": "2019-01-01",
    "report_date": "2019-01-01",
    "description": "肝脏边缘光滑，各叶大小比例正常，肝内可见多发类圆形、不规则形异常信号影...",
    "diagnosis": "肝内及脾脏多发异常信号影，考虑转移瘤可能； 2.盆腔术后改变；..."
  }
}
```

**语义**：某次就诊执行了某项检查，并记录了检查日期、报告日期、描述和诊断结论。

---

### 5. HAS_LAB_RESULT（就诊 → 检验）

```json
{
  "type": "HAS_LAB_RESULT",
  "from": {
    "label": "Visit",
    "id": "47448010"
  },
  "to": {
    "label": "LabItem",
    "id": "血小板分布宽度"
  },
  "properties": {
    "value": 32.9,
    "unit": "%",
    "reference_range": "5～42.3",
    "abnormal_flag": null,
    "hint": null
  }
}
```

**语义**：某次就诊产生了某项检验结果，包含定量值、单位、参考范围和异常提示。
